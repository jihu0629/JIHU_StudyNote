# 스터디 로그 개요

매일(또는 공부한 날마다) 무엇을 공부했는지 짧게 기록하는 공간입니다.

## 새 로그 추가하는 법

1. `docs/log/YYYY-MM-DD.md` 형식으로 파일을 만듭니다. (예: `2026-09-05.md`)
2. 아래 템플릿을 복사해서 사용하세요.
3. `mkdocs.yml`의 `nav > 스터디 로그` 아래에 파일을 추가합니다.

## 템플릿

```markdown
# 2026-09-05

## 오늘 공부한 것
-

## 어려웠던 점
-

## 내일 할 일
-
```
