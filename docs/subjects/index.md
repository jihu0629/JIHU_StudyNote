# 전공 공부 개요

과목별 공부 노트를 모아두는 공간입니다. 새 과목을 추가하려면:

1. `docs/subjects/` 폴더에 `과목이름.md` 파일을 새로 만듭니다.
2. `mkdocs.yml`의 `nav > 전공 공부` 아래에 파일 경로를 추가합니다.

## 현재 과목 목록

- [자료구조 (예시)](data-structures.md)

## 노트 작성 팁

- 한 페이지 = 한 과목(또는 한 단원)으로 구성하면 관리하기 편합니다.
- `tags` 플러그인이 활성화되어 있으니, 페이지 상단에 태그를 달아두면 나중에 관련 개념을 모아보기 좋습니다.

```markdown
---
tags:
  - 자료구조
  - 알고리즘
---
```
